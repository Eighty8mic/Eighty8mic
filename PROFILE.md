# Darnell

**Ex-employee. Current builder.** I used to sit in meetings about software.
Now I write it.

## The short version

I spent years on the other side of the screen — using tools other people
built, waiting on other people's roadmaps, filing tickets and hoping.
Eventually "I could probably figure this out myself" won the argument. So I
quit assuming someone else would build the thing, and started building it.

No CS degree. No bootcamp shortcut. Just a lot of broken builds, a lot of
Stack Overflow tabs, and a stubborn refusal to go back to a desk where the
software runs *me* instead of the other way around.
